# Flutter App Skill

Use this skill for Flutter mobile app work.

Rules:
- Inspect pubspec.yaml.
- Follow existing state management pattern.
- Keep UI simple and consistent.
- Run flutter analyze.
- Run flutter test if available.
- Avoid broad widget tree rewrites.
- Consider responsive screen sizes.

For Bible/meditation apps:
- prioritize calm UI
- readable typography
- Korean text legibility
- consistent spacing
- accessibility where practical
