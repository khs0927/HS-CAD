# Security Audit Skill

Use this skill for security-sensitive work.

Check:
- secrets
- auth flows
- payment flows
- database writes
- cloud permissions
- deployment config
- environment variable handling
- dependency risks
- unsafe shell commands

Use:
- gitleaks if available
- trufflehog if available
- semgrep if available
- npm audit if available
- pip-audit if available

Never print secrets.
