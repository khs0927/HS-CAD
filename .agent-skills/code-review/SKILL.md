# Code Review Skill

Use this skill when reviewing code, diffs, PRs, or generated patches.

Checklist:
- Does the code satisfy the requirement?
- Are there unrelated changes?
- Are there missing tests?
- Are edge cases handled?
- Is error handling explicit?
- Are types safe?
- Are secrets exposed?
- Are protected paths touched?
- Is the change easy to rollback?
- Does the code follow existing style?

Never edit in review mode unless asked.
