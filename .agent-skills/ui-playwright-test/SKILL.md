# UI Playwright Test Skill

Use this skill for UI changes.

Required workflow:
1. Identify changed pages/components.
2. Start dev server if needed.
3. Use Playwright for browser smoke test.
4. Check console errors.
5. Check network errors.
6. Test mobile width around 390px.
7. Test desktop width around 1440px.
8. Capture screenshots if possible.
9. Fix obvious issues and rerun.

Final report:
- tested routes
- viewport sizes
- console/network errors
- screenshots path if any
- remaining visual risks
