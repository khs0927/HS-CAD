# AI Run Records

This folder stores AI task plans, verification logs, QA reviews, and screenshots.

For non-trivial tasks, future agents are encouraged to create:
- `plans/YYYY-MM-DD-task-name.md`
- `verification/YYYY-MM-DD-task-name.md`
- `reviews/YYYY-MM-DD-task-name.md`
- `screenshots/` if UI testing is performed

This helps future agents understand prior decisions, inspect historical test results, and avoid repeating mistakes.
