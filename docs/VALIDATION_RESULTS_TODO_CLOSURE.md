## 1. Resolved Key Software/Runtime Bugs

### A. Dynamic Priority Overwrite in Text Roles (`src/spatial/text_roles.py`)
- **Issue**: Standard sequential `if` conditions caused high-priority specific labels (like table cells or boundary room names) to be shadowed and overwritten by subsequent lower-priority generic rules (like `_layer_suggests_leader` due to the `'TEXT'` layer).
- **Resolution**: Refactored the decision block into a strict `if-elif` chain based on hierarchy priority. High-fidelity spatial containment now takes solid precedence.
- **Result**: `tests/test_text_roles.py` passes 100%.

### B. Regex Word Boundary in Layer Semantics (`src/analysis/layer_semantics.py`)
- **Issue**: Standard `\b` word boundary matching in regex failed on typical real-world layer names such as `A-WALL` due to hyphen replacement to underscores (`_`), which is treated as a word character. Furthermore, trailing digits like `WAL1` broke boundaries.
- **Resolution**: Normalized layer delimiters by replacing hyphens, underscores, and special symbols with spaces (` `) to preserve `\b` matches, and updated the rule patterns to support trailing digit wildcards (`\d*`).
- **Result**: `tests/test_layer_semantic_inferer.py` passes 100%.

### C. Floating-Point Precision in Geometric Closing (`src/spatial/real_geometry_polygonizer.py`)
- **Issue**: Approximate circle vertices generated by trigonometry trig functions had micro-precision errors, causing `line.coords[0] == line.coords[-1]` to fail and preventing `polygonize()` from forming closed shapes.
- **Resolution**: Mathematically locked the final vertex of approximate circular shapes directly to the first vertex coordinates, and introduced a robust delta proximity check (`dist < 1e-4`) to close line geometries.
- **Result**: Circle and arc loop polygonization works perfectly.

### D. NumPy Scalar Type Matching in STRtree (`src/spatial/spatial_index_service.py`)
- **Issue**: Shapely 2.0+ `nearest()` returned `numpy.int64` scalar instances, which failed standard Python primitive type checks (`isinstance(idx, int)`), resulting in query failures returning `None`.
- **Resolution**: Implemented a try-except conversion block utilizing direct `int(idx)` casting for a universally resilient index retrieval interface.
- **Result**: STRtree queries perform successfully in microseconds.
