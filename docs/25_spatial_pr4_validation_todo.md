# 25. PR #4 Spatial / Text / Area Validation TODO

This document tracks validation work that needs to be done in a real HS-CAD Windows workspace.

The PR #4 code is designed to be non-mutating. It reads `fileized/json/*.json` artifacts generated by PR #3 and writes derived analysis files only.

## Current scope

PR #4 adds foundation modules for:

- spatial containment analysis
- boundary extraction from closed polylines, circles, connected line loops, ARC+LINE segment loops, and HATCH boundary paths
- text role inference
- area element inference
- spatial relationship graph JSON export
- optional spatial backend abstraction with pure-Python fallback and Shapely adapter
- optional open-source backend registry and discovery

Generated artifacts:

## Non-goals for PR #4

PR #4 does not mutate drawings.
PR #4 does not guarantee legal/quantity-survey-grade area results.
PR #4 does not infer drawing scale or unit conversion.
PR #4 does not replace human review.
