# HS-CAD Final Live Runner Execution Policy

## Default

Execution is disabled by default.

## Allowed first implementation scope

- copied DWG only
- one harmless allowlisted alias
- one command only
- explicit manual flag
- explicit operator approval
- audit and delta required

## Disallowed

- original DWG path
- batch execution
- unknown alias
- destructive alias
- automatic approval
- hidden environment approval
- no-audit execution
- no-delta execution
