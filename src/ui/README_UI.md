# Future Local UI

This folder prepares a PySide6-based desktop UI without making PySide6 a required dependency.

Planned screens:
1. DWG selection
2. XiCAD path selection
3. Drawing scan
4. Architecture audit report
5. Natural-language or JSON command entry
6. Dry-run preview
7. Execute on a copied DWG
8. Post-scan and diff report

The UI must call the same validated command pipeline used by the CLI.
