# Final Report Policy

Every final response after a coding task must be in Korean unless instructed otherwise.

Include:

1. Summary
2. Changed files
3. What changed
4. Verification commands and results
5. Git diff review summary
6. Remaining risks
7. Rollback plan
8. Self-evaluation

Self-evaluation format:

- Requirement match: 0-5
- Verification status: Passed / Partial / Failed / Not run
- Risk level: Low / Medium / High
- Rollback ease: Easy / Medium / Hard
- Confidence: 0-100%

Never claim full success if verification did not run.
